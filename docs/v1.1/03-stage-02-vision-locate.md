## 2. 关键决策（踩坑记录）

1. **弃用 ImageMagick 子图搜索**：600×1304 屏 + 220×60 模板实测 **3.4s**，不可用。
2. **弃用纯 SSD**：对低对比区域会误报——实测模板在 (30,2020) 却匹配到 (280,1104)，分数 0.897。
3. **改用 NCC**：对亮度不敏感，纯色区域分母趋零直接判负；阈值默认 **0.9**（0.85 会放进 0.878 的假阳性）。
4. **步长自适应**：大模板（>4000px²）用步长 4，否则 2；精修半径随之加大，大模板耗时从 1319ms 降到 **544ms**。
5. **视觉指纹 dHash**：微信无 a11y 时，用 9×8 灰度差分哈希补足页面身份（64bit）。
