# v1.1 · 00 需求收集与评估 / 可行性分析草案（P0）

> 状态：已归档（01/02 已锁定）
> 版本：v0.2　日期：2026-11-25　分支：`feature/v1.1-p0`
> 上游：[../06-scenario-analysis.md](../06-scenario-analysis.md)（真实场景失败分析）
> 目标：把两次真实任务的「错误尝试 3–4 次、耗时 4 分钟」降到「0–1 次、2 分钟内」

## 1. 背景与来源

v1.0.0-rc 的两个真实任务（微信发图、B 站读最新评论）虽然成功，但暴露出六类根因（R1–R6）：

| 根因 | 现象 |
| --- | --- |
| R1 无页面身份判定 | 进错 B 站、把浏览器悬浮视频当成目标 |
| R2 无视觉定位原语 | 微信全流程靠人从截图估坐标 |
| R3 无点击后断言 | 点了 × 没关掉，流程继续 |
| R4 无遮挡处理 | 悬浮视频/键盘/权限提示 |
| R5 无能力预检 | 微信相册权限没提前发现 |
| R6 决策粒度过粗 | 每步整屏读图 |

本次迭代只做 **R1、R2、R3**（P0），R4/R5/R6 留到 v1.2。

## 2. 目标与非目标

**目标**：让 Agent 在「多实例、无 a11y、有浮层」的真实场景下，能自助地
「确认自己在哪 → 找到目标 → 操作 → 验证结果」，减少人工试错。

**非目标（v1.1）**：

- OCR / 文本理解（tesseract 未安装，且属于 P2）；
- 多步任务编排 DSL（P2）；
- 遮挡自动关闭（P1）；
- 跨设备/远程。

## 3. 需求候选清单（RC）

| ID | 需求 | 来源 |
| --- | --- | --- |
| RC-01 | 返回「我在哪个应用/页面」的指纹（包名 + 关键文本 + 窗口类型） | R1 |
| RC-02 | 动作后自动等待并断言「预期变化」 | R3 |
| RC-03 | 给定模板图，在屏幕上定位并返回坐标 | R2 |
| RC-04 | 按文本点击（选择器优先、坐标兜底） | 06 §6 P1 |
| RC-05 | 识别悬浮窗/输入法/权限弹层 | R4 |
| RC-06 | 动作前能力预检（媒体权限、FLAG_SECURE） | R5 |
| RC-07 | 失败时返回可诊断信息（当前指纹、候选匹配、截图） | R3/R6 |
| RC-08 | 上述能力对 a11y / root / gkd 三种驱动尽量通用 | 架构一致性 |

## 4. 可行性判定（含本机实测）

| RC | 结论 | 依据 |
| --- | --- | --- |
| RC-01 | ✅ 可行 | 驱动已能返回 `appId`、根节点文本；补「关键文本哈希 + 窗口类型」即可 |
| RC-02 | ✅ 可行 | 服务端轮询 `captureSnapshot` 做文本断言；图像差分可用 `magick compare` |
| RC-03 | ✅ 可行（需换算法） | **实测**：`magick compare -subimage-search` 在 600×1304 屏 + 220×60 模板上耗时 **3.4s**，太慢；改用「灰度 raw + JS 粗到细匹配」，小样本实测 **13ms**，灰度转换 **~200ms** |
| RC-04 | ✅ 可行 | 已有 `execSelector` + selector-lite，补一个 `tapText` 封装 |
| RC-05 | ⚠️ 有条件 | 驱动可读 `windows` 判断 IME；PiP 需按窗口类型与包名过滤，部分 ROM 不可靠 |
| RC-06 | ✅ 可行 | 驱动侧可查 `PackageManager` 权限；FLAG_SECURE 靠截图失败码 |
| RC-07 | ✅ 可行 | 统一错误体 + 最近帧 |
| RC-08 | ✅ 可行 | 视觉/指纹逻辑放服务端，三种驱动都能用；断言只依赖 `/api/*` |

## 5. 关键技术风险

| ID | 风险 | 触发条件 | 早期信号 |
| --- | --- | --- | --- |
| VR-01 | 模板匹配误报 | 模板过小/大面积纯色/动态画面 | 匹配分数接近阈值、多个候选 |
| VR-02 | 分辨率/缩放不一致 | 不同设备密度、分屏、悬浮窗 | 命中位置偏移 |
| VR-03 | 动画导致断言失败 | 页面转场、加载圈 | 断言超时但实际已成功 |
| VR-04 | 指纹不稳定 | 页面文本变化（时间、数字） | 同一页面哈希漂移 |
| VR-05 | 性能退化 | 全屏搜索 + 大模板 | 单次 > 1.5s |
